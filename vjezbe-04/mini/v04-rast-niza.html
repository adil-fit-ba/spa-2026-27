Niz je pun. Za koliko ga proširiti?

Niz je jedan kontinuiran blok memorije i ne može se produžiti na istom mjestu. Kad se napuni, pravi se novi, veći niz i u njega se kopiraju svi dosadašnji elementi. Pitanje je koliko veći.

Proširenje sa 4 na 8: kopiraju se 4 elementa, pa se upisuje peti. Što je niz veći, proširenje više košta.

Pitanje s predavanja P01 (05.10.2026)

Za koliko proširiti niz kad je pun? Jedan odgovor je bio „za 1“, a drugi „za 50 % ili 100 %“. Predavač je rekao da se u praksi koristi 50 % ili duplo. Na vježbama V01 prosiriListu udvostručuje kapacitet. Ovdje poredimo sve tri mogućnosti.

C++ · Analiza.h (V04)
enum class Rast { PlusJedan, PutaJedanIPo, PutaDva };

// DATO: novi kapacitet za izabranu strategiju
long long noviKapacitet(long long max, Rast rast)
{
	if (rast == Rast::PlusJedan)
		return max + 1;
	if (rast == Rast::PutaDva)
		return max * 2;
	long long dodatak = max / 2; // x 1,5 (najmanje + 1)
	return max + (dodatak > 0 ? dodatak : 1);
}

Kalkulator · broj kopiranja za n dodavanja

+1 kopira n(n − 1)/2, a ×2 manje od 2n

Broj kopiranja računa JavaScript istom petljom kao kopiranjaPriRastu. Za n koje je izmjereno u C++ programu rezultat se poredi s njegovim (v04-mjerenje.json).

C++ · Analiza.h
long long kopiranjaPriRastu(int n, Rast rast)
{
	long long max = 1, brojac = 0, kopirano = 0;
	for (int i = 0; i < n; i++)
	{
		if (brojac == max)
		{
			kopirano += brojac; // prosirenje kopira sve dosadasnje elemente
			max = noviKapacitet(max, rast);
		}
		brojac++;
	}
	return kopirano;
}
+1Proširenje je pri svakom dodavanju: kopira se 1, pa 2, pa 3, … , pa n − 1 elemenata. Zbir je n(n − 1)/2, dakle O(n²) za n dodavanja.
×2Proširenja kopiraju 1, 2, 4, 8, … elemenata. Svako je duplo veće od prethodnog, pa je zbir svih manji od dvostrukog zadnjeg, a zadnji je manji od n. Ukupno je manje od 2n.
prosjekPojedino proširenje kod ×2 je O(n), ali je rijetko. Raspoređeno na sva dodavanja, jedno dodavanje u prosjeku kopira manje od 2 elementa: konstantno. To je ideja amortizovane analize.
