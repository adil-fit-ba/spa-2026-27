Koliko puta se izvrši petlja?

Metoda brojanja koraka: svaka naredba koja se izvrši računa se kao jedan korak, a zbir koraka zapisuje se kao funkcija T(n).

Ovo je analiza koda (na predavanju: a priori): broj koraka se izvodi iz koda, prije pokretanja, pa ne zavisi od programskog jezika, kompajlera ni računara. Mjerenje vremena (a posteriori) zavisi od svega toga i dolazi tek nakon pokretanja. Na sljedećim slajdovima isti model primjenjuje se na sumu niza i na osam obrazaca petlji iz Analiza.h.

Živi primjer

Suma niza, korak po korak

Svaki klik izvrši jednu naredbu. Brojač uz naredbu raste svaki put kad se ona izvrši.

C++ · suma niza
int suma(int a[], int n)
{
	int s = 0;
	for (int i = 0; i < n; i++)
		s = s + a[i];
	return s;
}

Prostor: niz a zauzima n lokacija, a varijable n, s i i još tri, pa je prostor n + 3, red veličine n.

Ilustracija u web pregledniku. Vrijednosti u nizu su izmišljene i ne utiču na broj koraka.

Izmjereno

Kako broj iteracija raste s n

Sporo rastu log log n, log n i √n: i za milion elemenata broj iteracija ostaje mali. Linearne petlje (i++, i += 2, i--) rastu jednako kao n. Ugniježđene petlje rastu kao n²: kad n poraste 10 puta, broj iteracija poraste 100 puta.

Analiza.h · petljaPutaDva
// for (i = 1; i < n; i *= 2)
long long petljaPutaDva(int n)
{
	long long b = 0;
	for (long long i = 1; i < n; i *= 2)
		b++;
	return b;
}
Analiza.h · petljaZavisna
// for (i = 0; i < n; i++)
//     for (j = 0; j < i; j++)      <- unutrasnja zavisi od vanjske
long long petljaZavisna(int n)
{
	long long b = 0;
	for (int i = 0; i < n; i++)
		for (int j = 0; j < i; j++)
			b++;
	return b;
}
Analiza.h · petljaKorijen
// p = 0;
// for (i = 1; p <= n; i++)
//     p = p + i;                    <- p = 1, 3, 6, 10, ...
long long petljaKorijen(int n)
{
	long long b = 0;
	long long p = 0;
	for (long long i = 1; p <= n; i++)
	{
		p = p + i;
		b++;
	}
	return b;
}
Analiza.h · petljaLogLog
// p = 0;
// for (i = 1; i < n; i *= 2)
//     p++;
// for (j = 1; j < p; j *= 2)        <- broji se samo ova petlja
long long petljaLogLog(int n)
{
	long long p = 0;
	for (long long i = 1; i < n; i *= 2)
		p++;
	long long b = 0;
	for (long long j = 1; j < p; j *= 2)
		b++;
	return b;
}

Provjera

Pitanja za provjeru

Odgovor prvo zapišite, pa otvorite.

1. Koliko puta se u sumi niza provjeri uslov i < n i zašto to nije n?

n + 1 puta. Uslov je tačan n puta (za i = 0, 1, …, n − 1), a jednom, za i = n, mora biti netačan da bi petlja stala.

2. Koliko puta se izvrši tijelo petlje for (i = 1; i < n; i *= 2) za n = 1000?

3. Nacrtajte tabelu za for (i = 0; i < n; i++) for (j = 0; j < i; j++) i n = 5. Koliko je izvršavanja?

4. Kod for (i = n; i > 1; i--) izbroji n − 1 iteracija. Zašto se kaže da je red veličine n?

Red veličine zadržava samo najveći stepen od n, a konstante se zanemaruju. Isto vrijedi za n/2 kod i += 2 i za 3n + 4 kod sume niza: sve su to petlje reda n.

5. Za n = 1.000.000, koja petlja ima manje iteracija: p += i ili i *= 2?

1 / 6
